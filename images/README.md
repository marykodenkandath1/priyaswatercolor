# Photos

Put Priya's photos here, then point to each one from `js/data.js`:

- Prints: set `photo` on each product,
  e.g. `photo: "images/martini.jpg"`.
- Previous work (commissions gallery): put photos in `images/work/` and add each one to
  `PREVIOUS_WORK` in `js/data.js`. The comment above that list explains the options.
- Priya's portrait: set `SITE.portraitPhoto`, e.g. `"images/priya.jpg"`.

Use JPG, about 2000 px on the long side, under 1 MB each. Any photo left as `""` keeps
showing the generated watercolor-style stand-in.
